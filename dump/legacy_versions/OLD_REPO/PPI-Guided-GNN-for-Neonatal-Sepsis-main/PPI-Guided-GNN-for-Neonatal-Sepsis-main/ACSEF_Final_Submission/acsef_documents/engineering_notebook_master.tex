\section{Mathematical Derivations}
\subsection{ComBat Batch Harmonization}
For gene $g$ and sample $i$, ComBat models expression as $x_{gi} = \alpha_g + \mathbf{z}_i^\top\beta_g + \gamma_{g,b(i)} + \delta_{g,b(i)}\epsilon_{gi}$, where $b(i)$ is batch and $\mathbf{z}_i$ includes biological covariate (condition). Empirical Bayes shrinks $\gamma,\delta$ across genes.
\subsection{Multiplex Hypergraph Message Passing}
Each relation $r \in \{\mathrm{KEGG},\mathrm{STRING},\mathrm{CoExpr}\}$ defines hyperedge incidence $H^{(r)}$. Two HypergraphConv blocks produce relation-specific embeddings $h^{(r)}$, then relation attention computes $\alpha^{(r)} = \mathrm{softmax}(W_a[h^{(1)}\Vert h^{(2)}\Vert h^{(3)}])$ and $h = \sum_r \alpha^{(r)} h^{(r)}$.
\subsection{GRL / DANN Objective}
Training minimizes $\mathcal{L} = \mathcal{L}_{\mathrm{sepsis}} + \lambda_{\mathrm{dann}}\mathcal{L}_{\mathrm{domain}}$, with gradient reversal layer applying $-\alpha$ multiplier on domain branch gradients.
\subsection{Metrics and Confidence Intervals}
Primary metrics are AUROC, Accuracy, F1, Precision, Recall. 95\% bootstrap confidence intervals are computed by resampling predictions with replacement.
