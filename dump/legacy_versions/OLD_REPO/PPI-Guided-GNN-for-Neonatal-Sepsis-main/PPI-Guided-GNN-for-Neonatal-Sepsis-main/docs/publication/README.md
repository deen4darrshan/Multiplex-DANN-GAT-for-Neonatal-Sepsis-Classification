# Publication Package

This folder contains publication ready assets for the Osteogenesis Imperfecta project.

Folders
- `visuals`: static PNG figures suitable for print or slides.
- `interactive`: HTML visualizations for web or presentation.
- `tables`: CSV and markdown tables used in results.
- `architecture`: model architecture diagrams.

Key entry points
- `tables\metrics_summary.md`
- `tables\dataset_counts.md`
- `visuals\pipeline_overview.png`
- `architecture\oigatv2_architecture.png`
- `interactive\external_accuracy_by_holdout.html`

Regeneration
- `generate_publication_assets.py` rebuilds tables and figures from `Osteogenesis imperfecta\results`.
