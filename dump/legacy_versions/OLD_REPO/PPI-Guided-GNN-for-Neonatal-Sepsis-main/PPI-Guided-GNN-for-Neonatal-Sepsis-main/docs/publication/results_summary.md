# Results Summary

Primary takeaways
- Combined cohort CV results are near perfect but are considered optimistic due to dataset size and overlap risks.
- External holdout testing provides a more realistic assessment of generalization.
- Human only grouped 5 fold evaluation provides the strictest internal benchmark and reaches accuracy above the 0.76 baseline with tuned L2 Logistic Regression.
